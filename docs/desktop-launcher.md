# Desktop launcher and Windows build

## How close are we to a simple `.exe`?

The game is currently a playable browser vertical slice. This pass adds the desktop packaging layer needed to turn that same game into a user-friendly Windows application.

- **Playable browser slice:** available now
- **Desktop development launcher:** available after installing Node.js dependencies
- **Portable `.exe` / installer `.exe`:** build configuration is now included; it must be generated by running the build command on a Windows, macOS, or Linux development machine
- **Full game:** still in production; Chapter 1 and later regions remain to be expanded

## Developer build

Install Node.js LTS, then run:

```bash
npm install
npm start
```

On Windows, `start-game.bat` performs the dependency check and launches the desktop window.

## Create Windows executables

```bash
npm install
npm run build:win
```

The `release/` directory will contain:

- an installer executable
- a portable executable that can be launched without an installation step

The Windows installer creates a Start Menu entry and Desktop shortcut. The portable build is the simplest option for a user who wants to download and play.

## Design goal

The Electron shell keeps the hybrid game simple for players:

1. install or unzip the game
2. double-click the game executable
3. play in a dedicated window
4. use the existing Save Continuity and Restore Continuity controls

The browser build remains available for testing and easy sharing.
