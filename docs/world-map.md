# World Map and Region Structure

## Overview

The game world should feel fractured, layered, and intentionally unstable. It is not a single static world; it is a set of realities and folds that respond to memory, continuity, and lost identity.

## Major regions

### 1. The Black Glass Chamber

The opening space. A black, impossible room with no clear boundaries, designed to disorient and establish the tone.

Purpose:
- awakening
- first exploration loop
- identity ambiguity
- installation of the player’s relationship with De’juir

### 2. Maintenance Corridors

The first true physical structure. This region contains machine architecture, diagnostics, and evidence of the Hive Cooperation.

Purpose:
- establish the techno-synthetic environment
- reveal structure and institutional power
- introduce repair logic and mechanical world rules

### 3. Fractured Reality Zones

The first unstable areas where physics and continuity become unreliable.

Purpose:
- create tension and unpredictability
- show the danger of memory inconsistency
- support the status system with environmental threats

### 4. The Innerspace

A deeper, surreal network of layered reality. The environment behaves more like a folded memory architecture than a traditional map.

Purpose:
- major narrative expansion
- deeper identity and continuity exploration
- the reveal of deeper truth

### 5. The Deep Below

The under-layer of the world: where discarded versions and corrupted entities exist.

Purpose:
- cosmic horror pressure
- final act escalation
- reveal of the Under Deep Unseen
- deep identity conflict

### 6. Protected / Safe Fold (V.R.P. style space)

A temporary safe environment that acts as a refuge or narrative checkpoint.

Purpose:
- stabilization moments
- memory and story recovery
- a place to process information and revisit choice outcomes

## Region logic

The world should not be mapped as a simple linear progression. Instead:

- regions can be revisited in different ways depending on status states
- prior truths can unlock alternative routes
- the same location may have different meaning if the player’s memory or emotional state changes
- some regions only become coherent after key memory fragments are recovered

## Exploration philosophy

The world should communicate that reality is layered and not fully trustworthy. The player should feel:

- uncertainty
- suspicion
- curiosity
- dread

The map should feel like a broken machine of memory, not a neat game board.

## Goals for world-building

- create a coherent but unstable universe for the player to explore
- make every region feel connected to identity, continuity, and the Deep
- give each major area a distinct emotional function

## Future world-building requirement

Each region needs:

- a purpose in the narrative
- a gameplay function
- a visual identity
- a mechanical identity tied to status or reality instability
- a relationship to the Deep and Zero2’s continuity
