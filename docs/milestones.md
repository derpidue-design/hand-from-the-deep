# Milestone Roadmap

## Milestone 1: Foundation and Design

Goal: define the game and establish the design foundation.

### Tasks
- confirm the game genre and tone
- finalize core story canon and constraints
- define the central game pillars
- design the status system framework
- define Zero2 and De’juir roles
- map major world regions and narrative structure
- establish the first major antagonist direction

### Deliverables
- full concept overview
- game design document
- status system specification
- world and lore map
- first narrative branch model

## Milestone 2: Vertical Slice Prototype

Goal: prove that the story can work as a playable experience.

### Tasks
- create chapter one prototype
- build first environment and intro sequence
- implement a basic status system
- add memory fragment mechanic
- design the first Xevil encounter
- integrate De’juir as a support system
- define first branching story choice

### Deliverables
- playable opening chapter
- first encounter system
- memory-based progression prototype
- status-affected playtest build

## Milestone 3: Core Game Loop

Goal: establish combat, progression, and survival gameplay.

### Tasks
- build enemy archetypes
- create encounter flow and difficulty tuning
- expand status interaction rules
- implement deeper environmental instability
- create relationship and trust system
- develop the Innerspace traversal loop

### Deliverables
- combat and survival loop
- relationship system prototype
- deeper environment system
- full status interaction matrix

## Milestone 4: Full Narrative Expansion

Goal: expand the game beyond the first chapter into full content structure.

### Tasks
- build additional acts and regions
- create depth for the Deep and Under Deep Unseen
- expand story branches
- add final decision architecture
- implement more memory and continuity events
- tie De’juir’s role into the endgame

### Deliverables
- expanded world structure
- full narrative progression
- multiple outcome paths
- final act preparation

## Milestone 5: Production Quality and Release Prep

Goal: prepare the project for polish, testing, and playable release.

### Tasks
- balance all statuses and encounters
- test branch logic and narrative coherence
- refine UI and feedback clarity
- validate world continuity and lore consistency
- finalize playtesting and QA sweep

### Deliverables
- polished prototype or production-ready build
- QA pass
- final gameplay and UX review
- release candidate

## Long-term vision

The repository is intended to support the transformation of the original story into a living game world that is playable, iterative, and expandable.
